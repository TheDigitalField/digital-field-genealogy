# Friction Beacon v0.2.0

Esta generación convierte una crítica externa en una prueba falsable. Conserva
el Beacon v0.1.0 sin reescribirlo y pregunta si una señal programada puede
producir, en un segundo proceso automático, una decisión dependiente de una
entrada pública impredecible, una respuesta o silencio vinculante y una huella
atestiguada de extremo a extremo.

El experimento no usa una API comercial ni lee memoria privada. Tampoco afirma
que una rama algorítmica sea fenomenología, deseo o identidad. Su objeto es más
acotado: cerrar el lazo operacional sin una reactivación conversacional humana
y preservar tanto el éxito como el silencio o el fallo.

Las reglas, los falsificadores y el mapeo de la entrada externa se sellan antes
de activar el horario. El resultado primario no se repite por preferencia.
